# データモデル

本システムはJSONファイルをデータソースとして利用する。

MVPではデータベースを利用しない。

---

# 設計方針

本システムの中心エンティティは Photo とする。

地域、都道府県、撮影地点は写真を分類するための情報として扱う。

将来的に以下の閲覧方法へ対応できる構造とする。

- 地域別
- 都道府県別
- 撮影地点別
- タグ別
- キャラクター別
- 季節別

---

# ID命名規則

全データ共通。

以下のみ利用可能。

```text
英小文字
数字
アンダースコア(_)
```

例

```text
kanto

kanagawa

yokohama_station

photo001

hatsune_miku
```

禁止例

```text
横浜駅

YokohamaStation

yokohama-station
```

---

# Area

地域を表す。

```typescript
type Area = {
  id: string;
  name: string;
  description?: string;
};
```

例

```json
{
  "id": "kanto",
  "name": "関東",
  "description": "首都圏を中心とした地域"
}
```

---

# Prefecture

都道府県を表す。

```typescript
type Prefecture = {
  id: string;
  name: string;
  areaId: string;
};
```

---

# Location

撮影地点を表す。

```typescript
type Location = {
  id: string;

  name: string;

  prefectureId: string;

  address?: string;

  lat?: number;

  lng?: number;
};
```

例

```json
{
  "id": "yokohama_station",
  "name": "横浜駅",
  "prefectureId": "kanagawa",
  "address": "神奈川県横浜市西区高島2丁目16",
  "lat": 35.465,
  "lng": 139.622
}
```

---

# Tag

タグ情報。

```typescript
type Tag = {
  id: string;

  name: string;

  category?: string;

  color?: string;
};
```

例

```json
{
  "id": "night_view",
  "name": "夜景",
  "category": "scene",
  "color": "#1D4ED8"
}
```

---

# Character

キャラクター情報。

```typescript
type Character = {
  id: string;

  name: string;

  series?: string;
};
```

例

```json
{
  "id": "hatsune_miku",
  "name": "初音ミク",
  "series": "VOCALOID"
}
```

---

# Photo

写真データ。

```typescript
type Photo = {
  id: string;

  title: string;

  image: string;

  thumbnail: string;

  date?: string;

  createdAt: string;

  locationId: string;

  tags: string[];

  characterId?: string;

  comment?: string;
};
```

---

## date

撮影日。

```text
YYYY-MM-DD
```

形式。

古い写真など撮影日不明の場合は未設定を許可する。

---

## createdAt

登録日時。

必須。

```text
ISO8601
```

形式。

---

# Photo.tags

Tag.idを保持する。

例

```json
{
  "tags": [
    "ar_photo",
    "night_view"
  ]
}
```

表示時

```text
ARフォト

夜景
```

へ変換する。

---
