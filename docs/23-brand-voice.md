# Photo Atlas ブランドと言葉の指針

## ブランド

**Discover Japan through photos**

**Photo Atlas — 地図から辿る写真館**

写真に残った旅の断片を巡る場所。写真と場所に残された記録を、地図から静かに辿る。

旅行ガイド、観光サイト、SNS、写真管理サービスとしてではなく、古い写真館・旅のアルバム・地図帳・日記帳のあいだにある体験を目指す。

## 大切にする感覚

探索、発見、旅、記憶、風景、場所、季節、光、余白。

写真が主役。言葉は写真を説明しきらず、次の一枚や場所へ進むきっかけにする。

## 文体

- 短く、静かに、柔らかく書く。
- 説明を重ねず、想像の余地を残す。
- 機能名より、写真から場所へ辿る体験を伝える。
- 空状態は不備や管理状態ではなく、まだ出会っていない写真として表す。
- 操作・エラー・日付など、誤解を招くと困る情報は詩的にせず明確に伝える。

## 優先する言葉

写真、場所、旅、風景、記録、記憶、断片、巡る、辿る、残る、見つける、静かな、季節、光、余白、景色、写真館、アーカイブ。

## 避ける言葉・印象

攻略、コンプリート、ランキング、管理、データベース、観光ガイド、ARフォト専門、推し活中心、キャラクター中心。

「登録」「撮影地点」「おすすめスポット」のように、管理画面や観光案内を連想させる表現は、公開画面では必要な場合を除いて避ける。

## コピー例

| 用途 | 推奨 |
|---|---|
| サイト説明 | 写真に残った旅の断片を巡ろう |
| 地図導線 | 地図から写真を辿る |
| 場所の写真 | ここに残る写真 |
| 空状態 | ここには、まだ写真がありません |
| Memory | 写真と閲覧者の間に置かれる余白 |

ユーザーが写真へ添えたタイトル・コメント・タグは作品データとして扱い、ブランドコピーの一括置換対象にしない。
