# コンテンツ登録ガイドライン

本ドキュメントは写真登録時のルールを定義する。

---

# 基本方針

利用者が後から見返した際に内容を理解できる情報を残す。

---

# Photo.title

必須

推奨

```text
10〜40文字
```

例

```text
横浜駅の夜景

山下公園の夜景

赤レンガ倉庫のイルミネーション
```

---

# Photo.comment

任意

推奨

```text
500文字以内
```

---

記載例

```text
横浜駅東口付近で撮影したARフォト
```

---

# Tag

推奨

```text
1〜10個
```

---

例

```text
旅の記録
夜景
季節
```

---

# Character

キャラクターが存在する場合のみ設定する。

---

# 撮影日

判明している場合は設定する。

不明な場合は未設定を許可する。

---

# Location

必ず既存撮影地点を確認する。

---

禁止

```text
横浜駅

横浜駅東口

横浜えき
```

のような重複登録。

---

# 品質方針

以下を推奨する。

- ピンボケを避ける
- 極端な低解像度を避ける
- サムネイル作成を行う
