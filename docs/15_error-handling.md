# エラーハンドリング

本ドキュメントはエラー発生時の挙動を定義する。

---

# 基本方針

サイト全体を停止させない。

利用者へ理解できるメッセージを表示する。

---

# 404

対象

```text
/area/[id]
/prefecture/[id]
/location/[id]
/photo/[id]
```

存在しないIDの場合。

---

表示

```text
404 Not Found

ページが見つかりません

TOPへ戻る
```

---

実装

```typescript
notFound()
```

使用。

---

# 写真未登録

撮影地点に写真が存在しない場合。

表示

```text
写真が登録されていません
```

---

# 撮影日未設定

Photo.date が未設定の場合。

表示

```text
撮影日不明
```

---

ソート

```text
最後尾
```

とする。

---

# 画像ファイル未検出

原寸画像が存在しない場合。

---

表示

```text
No Image
```

プレースホルダ画像表示。

---

# サムネイル未検出

プレースホルダサムネイル表示。

---

# GPS未設定

Location に

```text
lat
lng
```

が無い場合。

---

Leafletへ表示しない。

---

撮影地点一覧には表示する。

---

# SVG地図取得失敗

表示

```text
日本地図を表示できません
```

---

統計情報などは継続表示する。

---

# JSON読込失敗

表示

```text
データを読み込めません
```

---

# Tag不整合

Tag.id が存在しない場合。

表示

```text
不明タグ
```

---

# Character不整合

Character.id が存在しない場合。

表示

```text
不明キャラクター
```

---

# Leaflet初期化失敗

表示

```text
地図を表示できません
```

---

地点一覧表示は継続する。

---

# 想定外エラー

表示

```text
エラーが発生しました

時間を置いて再度お試しください
```

---

本番環境ではスタックトレースを表示しない。
