
---

# 概要

写真と場所に残された断片を辿る写真館。

利用者は日本地図から写真へ、写真から場所へと旅の断片を辿る。

旅行ガイド、観光サイト、SNS、写真管理サービスではなく、

```text
写真館

旅のアルバム

地図帳と日記帳のあいだ
```

のような静かな探索体験を目指す。

---

# 利用フロー

```text
Photo Atlas
 ↓

```
