# プロジェクト名

ARフォト図鑑

---

# コンセプト

```text
地図から辿る写真図鑑
```

---

# 概要

ARフォトおよび通常写真を蓄積・公開するWebサイト。

利用者は日本地図から辿りながら写真を閲覧できる。

SNSのような時系列消費ではなく、

```text
アーカイブ

図鑑

旅行記録
```

として利用できることを目的とする。

---

TOP
 ↓
