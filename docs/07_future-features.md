# 将来機能

本ドキュメントはMVP完了後の拡張候補を定義する。

---

# 優先度A

## タグページ

URL

```text
/tag/[id]
```

例

```text
/tag/night_view
```

表示内容

- タグ情報
- 写真一覧

---

## キャラクターページ

URL

```text
/character/[id]
```

例

```text
/character/hatsune_miku
```

表示内容

- キャラクター情報
- 写真一覧

---

## 季節ページ

URL

```text
/season/[id]
```

例

```text
/season/spring
```

- 写真一覧
