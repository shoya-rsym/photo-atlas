# Photo Import Tool

管理者専用のローカル写真登録ツール。静的サイト（GitHub Pages）には含まれない。

```bash
npm run import      # http://127.0.0.1:4321 （PORT で変更可）
```

エクスプローラーからはリポジトリ直下のファイルをダブルクリックでも起動できる（サーバー起動 + ブラウザ自動オープン）。

- `Photo-Import.cmd` … 写真登録画面
- `Photo-Manage.cmd` … 写真管理画面

サーバーが既に起動中なら、ブラウザだけ開く。停止はコンソールウィンドウを閉じる。初回は `node_modules` が無ければ `npm install` を自動実行する。Node.js のインストールが必要。

## 使い方（撮影セッション単位）

1. 撮影場所を入力（Enter で先頭候補。未登録なら「新しい撮影地点」を開いて入力。検索ボタンで OpenStreetMap から名前・都道府県・住所・座標・IDを取得）
2. 撮影日を入力（`202604` / `20260415` / `2026-04-15` / `2026年4月15日`、空欄=撮影日不明）
3. タグ・キャラクターを複数選択（絞り込み欄で Enter、なければ新規追加）
4. 画像 or フォルダをドラッグ＆ドロップ
5. 「登録前確認へ」→「登録実行」

前回と同じ設定は「最近使った設定」から1クリックで復元できる。
登録後も設定は保持されるので、次の画像を続けてドロップできる。

撮影場所の検索には OpenStreetMap の Nominatim 公開サービスを利用する。検索ボタンを押すと先頭候補を自動入力し、住所は「都道府県＋市区町村＋町名・丁目＋番地」の形に整えます（郵便番号・国名は含みません）。ID は OSM 要素 ID から生成します。都道府県を特定できない場合は選択が必要。検索はボタンを押した時だけ実行し、利用条件に従いリクエスト間隔を1秒以上空ける。検索結果は `locations.json` に保存されるため、画面に表示される OpenStreetMap の帰属表示を維持すること。公開サービスのため、検索頻度や可用性に制限がある。

## 登録時の処理

- `src/data/photos.json` に追記（ID は `photoNNNN`）、必要に応じ `tags.json` / `characters.json` / `locations.json` も追記
- `public/photos/`（原寸。PNG・4K超は JPEG へ変換）、`public/thumbnails/`（長辺512px webp）へ配置
- 完了後に `scripts/validate-data.mjs` を実行。失敗時はファイル・JSON をロールバック
- EXIF / GPS は使用しない

## 重複チェック

画像の SHA-256 を `tools/photo-import/data/hashes.json` で管理（コミット対象）。
登録済み・選択内重複は初期状態で除外され、チェックを入れれば承知の上で登録できる。

## 代表写真

星アイコンで1枚指定すると `isCover: true` を photos.json に書き込む。
`Photo` 型・docs は未変更（設計変更提案待ち）。

## フォルダ名解析（設計のみ）

`lib/folder-name.mjs` の `parseFolderName()` が現在 `null` を返すスタブ。
`202604_横浜駅_初音ミク` → `{ date, locationQuery, characterQuery }` を返す実装に差し替えれば、
`app.js` の `applyFolderHint()` が入力欄へ自動反映する。

## 写真管理（登録後の修正・整理）

`npm run import` 起動後に http://127.0.0.1:4321/manage を開く（登録画面右上のリンクからも移動可）。

- **検索:** タイトル・タグ名・キャラクター名・地点名・コメントを横断検索（スペース区切りでAND、かな/カナ・全半角を区別しない）。「撮影日不明」「タグなし」「キャラクターなし」「代表写真」で絞り込み可
- **類似写真検索:** perceptual hash で見た目が近い候補ペアを検索（64bit差分8以下）。候補画像を見比べ、削除対象を明示選択してから削除できる。自動削除は行わず、画像解析できない写真は理由を表示する
- **選択:** クリック、Shift+クリックで範囲、「このページ/検索結果をすべて選択」
- **一括編集:** タグ追加・タグ削除（選択中の写真に付いているタグを件数付きで表示）・地点変更・複数キャラクター変更/解除・撮影日変更（`2026年4月15日` も入力可、空欄=不明）。新しいタグは一括編集または写真詳細編集から作成して対象写真へ追加できる。地点変更時、地点名＋番号形式のタイトルは新地点名に合わせて更新する。実行前に確認ダイアログ
- **キャラクター管理:** キャラクターを新規追加できる。写真に設定中のキャラクターは削除できない
- **選択操作:** 写真一覧の選択バーはスクロール中も画面下部に表示され、「選択解除」などをいつでも実行できる
- **ページ移動:** 最初・最後のページへ移動、ページ番号を指定した直接移動ができる
- **キャラクター指定:** 写真ごとに複数選択でき、詳細編集・一括編集・登録画面から設定できる
- **タイトル再編集:** 写真を1枚または複数枚選択し、「選択した写真のタイトルを再編集」を実行すると、地点ごとに空いている最小番号から再採番する。選択対象自身の番号はいったん空きとして扱うため、再実行しても不必要に番号が増えない。番号は選択外の既存タイトルと同じ桁数に整える
- **地点の新規追加と一括適用:** 写真を選択し、一括編集の「新しい地点を追加して選択中の写真に適用」から地点名・都道府県などを登録。追加した地点が選択中の全写真へまとめて適用される。ID は自動採番される
- **詳細編集:** カードをダブルクリック or 「編集」。タイトル・撮影日（`2026年4月15日` も入力可）・地点・キャラクター・タグ・コメント・代表写真（同地点の他の代表は自動解除）
- **更新の取り消し:** 情報を保存した後は、一覧上部の「更新前の保存情報に戻す」から直前の Photo-Manage 更新を1件取り消せる。履歴は再読み込み後も利用でき、次の Photo-Manage 更新で置き換わる。写真削除・写真登録やデータファイルの外部変更があった場合は無効になる
- **撮影地点情報:** 画面上部の「撮影地点情報を編集」から既存地点を選択。OpenStreetMap 検索で名前・都道府県・住所・座標を入力でき、住所は郵便番号・国名を除いた日本形式に整形。地点IDは変更不可。地点名の変更は同じ地点IDを参照する全写真に反映され、保存前に対象枚数を確認できる。タイトルがいずれかの登録地点名（または地点名＋半角空白＋数字）と完全一致する写真だけ、新しい地点名に合わせてタイトルを更新する。その他のタイトルは変更しない
- **削除:** photos.json・原寸画像・サムネイルを同時に削除。実体は `.local/trash/<日時>/` へ退避（photos.json の該当エントリ付き）。ハッシュも外すので再登録可能
- 地点の写真が0枚になると `validate` が孤立地点エラーにするため、「空の撮影地点を削除」ボタンを表示
- 操作ごとに `scripts/validate-data.mjs` を実行して結果を表示

## セキュリティ

127.0.0.1 のみ待ち受け、Host ヘッダ検証と POST のカスタムヘッダ必須で CSRF/DNS rebinding を防止。
